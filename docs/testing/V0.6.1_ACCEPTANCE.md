# V0.6.1 Acceptance

## Available Sources

- [x] Available offers All Sources, Personal, Plugin, and System filters.
- [x] Plugin Skills declared by a Codex plugin manifest appear under Plugin.
- [x] Plugin source labels appear in the list and detail view.
- [x] Plugin Skills remain read-only and do not count as Installed.
- [x] Personal and System source behavior remains unchanged.

## Safety And Boundaries

- [x] SkillDock does not scan undeclared folders across the plugin cache.
- [x] Invalid manifests and paths outside a plugin version directory are skipped safely.
- [x] Ambiguous multiple plugin versions are skipped instead of choosing one silently.
- [x] SkillDock does not install, remove, enable, disable, or update plugins.
- [x] Plugin hooks, runtime, MCP, apps, and permissions remain outside SkillDock.

## Regression

- [x] Library import, Installed filtering, Agent installation, GitHub updates, Settings, and translations still work.
- [x] Product owner accepted V0.6.1.
