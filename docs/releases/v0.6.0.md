# SkillDock V0.6.0

## Highlights

- Added `Available`, a read-only browser for Codex-discoverable Skills.
- Added Personal Skills from `~/.agents/skills` and existing Codex System Skills.
- Added All Sources, Personal, and System filters with source labels and duplicate-safe merging.

## Notes

- V0.6.0 covers Personal and System sources only. Available content stays separate from Library assets and Agent-installed copies.
- Plugin Skills remain planned for a later V0.6.x release. SkillDock does not scan `.codex/plugins/cache` or manage plugin installation, removal, or updates.
- Available is read-only. Reveal in Finder and Copy Path remain available.
- When a Codex Agent copy and System copy merge, ambiguous pre-V0.6 `.codex` translations appear only in Available System; unmerged Agent translations remain unchanged.
