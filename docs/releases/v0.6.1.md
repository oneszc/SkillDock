# SkillDock V0.6.1

## Highlights

- Added `Available`, a read-only browser for Codex-discoverable Skills.
- Added Personal Skills from `~/.agents/skills`, Codex Plugin Skills, and Codex System Skills.
- Added All Sources, Personal, Plugin, and System filters with physical source labels.
- Kept Available Skills separate from Library assets and Agent-installed copies.

## Safety

- Plugin Skills are discovered only through the `skills` path declared by each plugin manifest.
- Invalid manifests, escaped paths, symbolic-link escapes, and ambiguous multiple versions are skipped safely.
- SkillDock does not install, remove, enable, disable, or update plugins.
- Plugin hooks, runtime, MCP, apps, permissions, and lifecycle remain managed by Codex.
